| 权限与交付：选择范围后扫描 | 范围确认、诊断、签名及 CI 配置已有；见权限记录 | 原生默认／扩展／AI 授权、拒绝、重启矩阵未闭环，云端 CI 未运行 | 固定包真实反馈；不重置 TCC、不以终端测试代表应用权限 | 本批 S1 持续 |

| 更多缓存：逐项预览执行 | uv／npm／pip 已有固定规则及证据 | 新规则先研究重建条件及版本兼容，优先单条工具原生命令 | M3和规则证据满足，独立故障测试、前置复核与结果核验 | 条件式 M6 |
| 项目产物：理解归属再处理 | 项目账本、关系和空间图已有 | 删除需额外 Git受控内容、嵌套仓库、密钥、活动写入保护 | 没有运行证据不等于无人使用；工作树／源码不纳入通用删除 | 后续专项 |

| 重复文件：核对相同内容 | 未实现 | 独立选择普通文件范围，大小筛选、内容哈希与处理前复核 | 读取正文须独立授权，硬链接不作副本，每组至少保留一份 | 后续专项 |
| 应用管理：解释占用与卸载范围 | 未实现 | 先只读应用与关联数据账本，再设计卸载 | 共享／个人资料保留；归属不明只读，不按名称前缀删除 | 后续专项 |
| 历史／增长：核对结果及变化 | 清理历史、项目基线及AI会话基线已有 | AI持久化基线与普通扫描基线未实现，需独立定义范围 | 不把磁盘变化全部归因于清理，部分扫描不作增长结论 | 下一批只读 |

## 后续实施批次

1. 本批：S1 权限补验、S2 普通目录地图、S3 只读大文件、S4 验证与本地交付。具体步骤见 [首批实施计划](plans/2026-10-22-space-browser-delivery.md)。
2. 0.9.7 已交付统一独立概览和可比AI会话基线；持久化／普通扫描基线与结构化元数据关联仍待设计，不因只读交付而自动开放清理。
3. 条件批次：在 M3 闭环和规则证据充分后，挑选一条可重建缓存规则独立落地；找不到合格规则就继续只读诊断。
4. 后续专项：项目产物处理、重复文件、应用账本各自规划验收；跨平台、提权助手、常驻监控、杀毒和通用系统优化不纳入当前范围。

KISS／DRY 复用当前引擎、布局和执行复核；SOLID 保持只读分析与删除入口隔离；YAGNI 延后规则框架和独立扫描服务。MangoDisk 的静态参考与 CleanMyMac 的既有研究仅作为依据线索，不代表产品功能已经复刻或通过真机验收。
