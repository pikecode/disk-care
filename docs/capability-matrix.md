## 后续实施批次

1. 本批：S1 权限补验、S2 普通目录地图、S3 只读大文件、S4 验证与本地交付。具体步骤见 [首批实施计划](plans/2026-10-22-space-browser-delivery.md)。
2. 0.9.7 已交付统一独立概览和可比AI会话基线；持久化／普通扫描基线与结构化元数据关联仍待设计，不因只读交付而自动开放清理。
3. 条件批次：在 M3 闭环和规则证据充分后，挑选一条可重建缓存规则独立落地；找不到合格规则就继续只读诊断。
4. 后续专项：项目产物处理、重复文件、应用账本各自规划验收；跨平台、提权助手、常驻监控、杀毒和通用系统优化不纳入当前范围。

KISS／DRY 复用当前引擎、布局和执行复核；SOLID 保持只读分析与删除入口隔离；YAGNI 延后规则框架和独立扫描服务。MangoDisk 的静态参考与 CleanMyMac 的既有研究仅作为依据线索，不代表产品功能已经复刻或通过真机验收。
