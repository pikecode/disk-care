# 每轮修改记录模板

将下面条目加入 [修改与优化记录](change-log.md) 的索引和正文顶部；新编号使用当天尚未使用的下一个序号，替换所有方括号占位说明。修改前可标记“进行中”，完成后再补实际验证状态。

```markdown
<a id="change-YYYYMMDD-NNN"></a>

## YYYYMMDD-NNN｜[版本或版本未变] [本轮主题]

- **背景**：[用户反馈、已确认问题或优化目标。推测与事实分开写。]
- **修改内容**：[具体变更及用户可感知的行为；同版本追加修复、复测或撤销也要记录。]
- **涉及文件**：[主要文件或模块，不必穷举自动生成的编译产物。]
- **验证**：[实际执行的检查、结果、测试环境及跳过项目；模拟与真实测试分开。]
- **影响与限制**：[兼容性、权限与数据影响、未解决事项、旧版备份或回退方式。没有应用交付时明确说明。]
- **依据**：[相对链接到计划、设计、验证文档；截图和本地日志可列路径，并在文档中保留核心结论。]
```

索引行模板：

```markdown
| [YYYYMMDD-NNN](#change-YYYYMMDD-NNN) | [版本／类型] | [主题] | [进行中／已完成／待实机验收／已撤销及实际说明] |
```

完成前检查：

1. 编号唯一，索引与详情一一对应。
2. 未升级应用时不虚构新版本；应用交付、模拟测试和实机通过分别表述。
3. 相关本地链接存在，历史结论有来源；失败、回退、待确认事项没有省略。
4. 同一轮文档与代码调整纳入同一条记录，不为日志更新递归新增条目。
