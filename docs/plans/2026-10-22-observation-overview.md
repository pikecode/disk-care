# 统一观测概览与会话基线实施计划

**目标：** 在概览展示独立账本，并为 AI 完整统计提供明确可比的会话基线。

**架构：** 复用 App 中已有报告，不新增扫描、IPC 或持久化。基线保存在 App 内存，导航保留，重启清空；纯函数统一校验比较口径。

**技术栈：** React、TypeScript，现有检查脚本。

1. 新增 `src/aiBaseline.ts` 和断言：仅完整、无问题、有效数字的报告允许设基线；比较要求工具、根、来源、版本和分类规则一致，时间严格递增。
2. `src/AiData.tsx` 接入显式设定／替换基线、时间和分配块差值；`src/App.tsx` 保存会话状态，不写磁盘。
3. 概览复用项目／模型／AI 报告展示独立观测时间、范围和状态，提供导航；不跨账本累加，不称作可回收量。
4. 扩展 `scripts/check.mjs` 运行基线边界断言，运行统一检查，构建应用并核验完整签名后更新交付。
5. 同步进度、说明和修改记录；真实权限矩阵继续保留未验收，不通过重置权限构造结果。

取舍：持久化基线能跨重启，但增加敏感路径落盘与版本迁移；优先会话方案（KISS、YAGNI）。比较规则集中在纯函数（DRY、单一职责）；不增加通用快照框架。

边界：不解析对话或配置正文，不实现跨工具总量／增长；部分统计不能设基线。项目已有基线保持原规则。AI 元数据关联仍待独立格式验证。

实施结果：上述会话范围已随0.9.7本地交付；统一检查、AI模拟回归和两处签名通过。原生权限矩阵未运行，继续保留缺口；不将本轮作为整个M5完成。
