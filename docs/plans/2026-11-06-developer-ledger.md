# 开发工具空间账本首期

目标：将本机整理所得证据转化为可复用的专项分析，而不是按目录大小自动清理。

采用工具原生探测＋元数据账本，替代硬编码默认路径／整目录删除。Yarn／pnpm／Poetry调用固定路径查询命令，GUI环境用现有工具查找逻辑补齐常见安装位置；禁用Corepack网络与更新提示。自定义缓存超出常规缓存边界且不在所选范围时只显示位置，不扫描默认替代目录。

Rust基于系统选择的项目目录，检查Cargo.toml元数据及root/src-tauri两处约定，不解析正文、不执行cargo构建；分列incremental、deps、build、release，说明自定义Target未验证。Homebrew查询prefix，安装内容与var服务数据分开；数据库／日志／其他服务状态默认保护。每项显示用途、路径、观测、覆盖与影响；不生成跨类可释放总数。

共享35秒分析预算，单个原生命令最多2秒、单来源遍历最多3秒，沿用现有遍历条目上限／硬链接去重／跨设备与私有边界保护。取消在命令／文件系统调用之间生效，未访问项不是零占用。GUI选择、工具范围勾选与分析分开，结果保留切页状态。

Homebrew原生预览是独立只读操作，固定cleanup --dry-run，不接收自定义命令；禁用自动更新／统计，最多返回100行／20000字符并显示截断，不换算承诺释放量。

KISS／DRY复用工具定位、command_path、measure_directory与作业互斥；SOLID观察与执行独立；YAGNI不引入规则插件系统或自动清理。M3／M6条件未满足，本轮不新增清理执行，先完成五类工具的可解释分析与原生预览。

文件：dev_tools.rs、core.rs／lib.rs、DeveloperTools.tsx、App.tsx／api.ts／types.ts／style.css、专项测试／模拟脚本及交付记录。

验证：非法工具／重复范围拒绝、路径解析与范围、数据库保护分类、Rust只读及不存在／取消语义；原生只读探测显式测试；UI范围确认／切页／预览／失败／取消／零写入，统一检查、打包与签名。只读专项不等同通用缓存清理已实现。

## 本轮实施结果

源码与五项自动测试已补齐：工具白名单、路径范围、服务数据保护、Rust元数据只读、缺失与未访问区分。真实四工具只读探测及Homebrew dry-run成功；浏览器模拟流程通过。打包签名结果以本轮修改记录为准。首期只读范围完成，后续优先补固定应用包权限验收，再独立评估单工具清理规则；不将账本完成等同清理执行完成。
