# 留白磁盘清理工具实施计划

**目标：** 在 macOS 上完成真实扫描、清理预览、选定缓存清理及空间核验。
**架构：** React 展示，Tauri 命令调用 Rust；单进程、本地存储、无通用 shell 接口。扫描只遍历固定目录，按需展开直接子目录。
**技术栈：** Rust、Tauri 2、React、TypeScript、Vite。

## 决策与范围
- 采用 Rust + Tauri，替代 Python 快速原型；增加工具链成本，换取桌面交付与原生文件访问。
- KISS/YAGNI：首版不做驻留、自动清理、管理员提权、联网分析和任意路径删除。
- SOLID：扫描、清理规则、桌面命令分别组织；DRY：复用路径校验和进程检查。
- 官方命令优先；uv、npm、pip 支持清理。Yarn/Gradle/应用数据先分析，不用通用递归删除兜底。
- Ollama 读取本地清单，逐模型删除仅在服务已运行时提供；不自动启动服务、不重置数据库密码。
- 扫描/预览不是删除授权；用户须在具体计划中再次确认。

## 实施与验证
1. 创建 React + Tauri 项目配置，安装 Rust 最小工具链与项目依赖。
2. 实现固定规则扫描、物理块统计、硬链接去重、符号链接保护、取消与进度。
3. 实现固定参数清理、运行依赖阻止、短效预览凭据、执行前复核及本地记录。
4. 实现中文界面、目录展开、筛选选择、确认对话框和历史结果。
5. Rust 单元测试验证边界、路径拒绝、硬链接、取消、凭据与失败处理；前端类型检查和构建。
6. 本机只读扫描与桌面启动检查；清理验证仅使用临时夹具，不清理用户真实缓存。
7. 打包 macOS .app 并写启动方式、已验证范围、权限与限制。

## 风险
依赖检测仅限本机可见进程与命令行；项目静态配置无法覆盖动态依赖。APFS 克隆、硬链接、快照与占用文件使估算不同于实际释放量。权限错误必须显示。桌面发布签名与公证留待对外发布。
