# REA 最小试用计划

目标：评估用户指定的 morluto/rea 是否能帮助分析同类应用的结构与行为，为留白功能对标提供证据。

方案一（本轮采用）：固定 rea-agents 6.7.0，在 output/rea-evaluation 独立目录用 CLI 做只读分析。方案二：运行 setup 注册 MCP 和配套技能，集成更直接但会改变代理配置，先不采用。遵循 KISS/YAGNI，不接入产品运行时；不新增清理能力。

1. 核对 GitHub 与 npm 来源、版本、许可证和 Node 要求，核验下载完整性；阅读入口，不运行安装生命周期脚本。
2. 独立安装运行依赖并执行帮助、能力检查；不注册代理、不安装分析器、不修改系统权限。
3. 优先分析自有留白应用包与可控前端构建产物，保存命令、结果和限制。常用位置未发现 CleanMyMac，若用户提供路径再确定该目标的下一步。
4. 原生深度分析依赖缺失则如实记录，不把元数据检查等同反编译或功能复刻。
5. 输出试用报告，更新修改日志 20261020-001；应用仍为 0.8.5，不重新打包。

边界：独立工作目录不是操作系统沙箱。仅执行已选择的静态分析命令，不执行目标程序、不注入进程、不抓用户网络流量或提取凭据。REA 是调查工具，不是 CleanMyMac 功能实现。不会运行会改动代理配置的 setup。
