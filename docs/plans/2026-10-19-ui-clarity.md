# 扫描与分析界面的清晰度改进

问题：权限说明持续堆积，扫描设置弹窗混合选择、系统设置说明和路径列表；首页标题抽象、结果说明重复，主要操作被长内容挤出。

目标：用户先知道做什么，再看需要的信息；不改变扫描范围、系统授权语义和清理保护。

方案一（采用）：现有页面渐进展开，扫描范围卡片化，授权说明折叠，操作栏固定；方案二：多页设置向导，层级明确但增加来回切换，本轮不采用。KISS/YAGNI 复用现有状态与组件；DRY 保留同一设置入口，避免新增权限状态机；展示与扫描/删除职责继续分离。

1. src/ScanAccess.tsx：两张范围选择卡片，默认常规；仅扩展/项目出现简洁权限卡；路径和操作步骤折叠。使用固定标题/底栏与可滚动内容。保留确认门槛、不伪造授权、不自动扫描。
2. src/App.tsx：首页改为直接标题和三步操作提示；范围改为短摘要、详细限制进入已有展开区。
3. src/ScanCoverage.tsx：不完整结果说明收敛为短状态、按需展开路径及原因和处理办法，设置失败仍可见。
4. src/CleanupAnalysis.tsx：收紧标题及说明，保留分类、影响提示、资格与过期逻辑。
5. src/style.css：沿用米白与绿色，只强化字号、对比、层级、留白与焦点；不加字体或组件依赖。清理旧授权样式后再增加新样式。
6. 更新受影响的八组界面脚本定位，新增 960×660/1180×820 检查：默认无需滚动即可开始、扩展底栏始终可见、折叠内容可用、取消与确认语义不变。
7. 生产构建和界面检查通过后交付 0.8.4，使用完整包签名并执行签名校验。旧版备份，签名变化可能要求用户重新授权。

不在本轮重新设计关系图和空间图算法，不新增扫描项或删除能力。视觉测试使用模拟 IPC，不以界面通过推断系统权限已生效。
