# 空间地图实施计划

> 用户已要求继续实施；本轮交付前文规划中的矩形树图，与已完成的关系图联动。使用 brainstorming、writing-plans、frontend-design 和 ponytail；当前无 Git 仓库，不创建提交或 worktree。

**目标：** 交付 0.5.0，让用户按面积发现项目产物大项，展开恢复条件并查看所属项目关系。

**架构：** TypeScript 纯函数从既有报告生成对象及矩形坐标，React 展示可聚焦按钮、等价列表和详情。ProjectLedger 管理三种视图和跨视图项目选择，RelationshipGraph 接收可选初始项目路径；Rust 扫描和清理接口不变。

**技术栈：** 现有 React、TypeScript、CSS 与 Rust/Tauri 构建工具，无新增依赖。

## 任务 1：数据与布局

文件：新增 `src/spaceLayout.ts`、`scripts/space-map-check.ts`。

1. 从项目直接产物生成观测权重，按路径生成身份；保留零占用对象但不绘制零面积。
2. 30 个大项之外聚合为其他项目；保留剩余项目和完整权重。
3. 实现沿长边、按权重平衡的递归二分，返回归一化坐标；同权重按 ID 排序。
4. 编译并运行无新依赖断言：比例、守恒、重叠、边界、稳定性、聚合、身份和非法权重。

## 任务 2：地图交互

文件：新增 `src/SpaceMap.tsx`，修改 `src/ProjectLedger.tsx`、`src/RelationshipGraph.tsx`、`src/style.css`。

1. 加入空间地图入口，保留默认关系图及账本。
2. 渲染等比例矩形、文字图例、观测范围和部分结果说明。
3. 实现项目/聚合展开、逐级返回、产物恢复条件、搜索、列表分页和键盘操作。
4. 「查看项目关系」精确定位相同路径项目；失效路径回退首个有效项目，不借大小猜测依赖。

## 任务 3：验收与交付

文件：新增 `scripts/space-map-ui-smoke.js`，更新 README、版本、验证记录和本计划。

1. Playwright 模拟 IPC 检查比例、展开、聚合、列表、关系跳转、键盘、空/部分数据、无删除调用及 960px 布局。
2. 前端生产构建、两套数据断言与已有三套界面检查通过；原生构建验证 Rust 接口兼容。
3. 交付 0.5.0，保留 0.4.0 回退备份，核验启动；清除本轮编译中间文件与开发预览服务。
4. 如实记录测试边界，不把观测合计描述为可释放量。
