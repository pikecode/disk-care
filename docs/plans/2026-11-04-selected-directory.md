# 独立文件夹只读分析

目标：不依赖全盘／缓存扫描，通过系统文件夹选择器明确选择目录，再确认后浏览占用、地图与大文件。

方案：采用NSOpenPanel，IPC不接收任意路径；替代方案自由输入路径更易误选且缺少系统范围选择，不采用。系统选择不代表已获得所有子目录权限，不自动更改TCC。

实现：Engine保存一个会话选择（不透明ID、目录路径、设备／inode），新选择使旧选择失效。children与observed_file复用统一根解析；固定扫描根行为保持。拒绝根目录/、符号链接和现有私有数据边界；相对路径校验／元数据遍历／分页／地图／大文件／Finder身份复核复用原逻辑。不将所选目录加入清理Scan或Action。

UI：空间概览增加选择文件夹卡片，先显示精确范围及只读说明，勾选后“分析所选目录”；取消不扫描，重新选择重置确认。统计使用已有模态浏览、取消和覆盖说明，权限不足不当成空目录。

KISS／DRY复用目录浏览与遍历。SOLID选择、分析与删除独立。YAGNI不持久化目录授权、不引入后台索引或通用删除。

验证：无扫描也可浏览、旧选择失效、根替换／链接／私有目录／越界拒绝、大文件定位复核、选择不能清理；模拟取消、确认、地图、下钻、分页、文件定位、拒绝及零执行。统一检查、打包／签名，原生选择器取消与真实用户选择范围验收分别记录，不操作用户文件删除。
