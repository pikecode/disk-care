# 参考工具后的应用管理功能与交互完善

目标：在现有双栏中增加应用分组／排序、所选应用本体占用检查和关联结果筛选。

对照依据：MangoDisk公开README说明覆盖空间分析／卸载／历史；CleanMyMac官方应用管理说明支持分组、名称／大小排序和资源详情。本轮只据公开功能说明借鉴组织方式，不宣称完成两个工具的动态等价验证。

采用方案：现有列表分组加详情；替代方案另建卸载和空间分析重复应用列表会割裂身份与选择，不采用。KISS／DRY复用measure_directory及互斥／取消；SOLID保持应用本体、关联数据和执行独立；YAGNI不批量预读所有包体积，不按不完整大小排序。

功能：
- 全部、已发现多个副本、受保护标识分组；同标识不等于相同内容，也不自动判断多余。部分目录列表下，多副本数只代表已发现范围。
- 名称正／倒序；搜索保留。受保护分组复用后端卸载保护策略的Apple标识／留白标识，不把它当签名认证。
- 所选应用明确点击计算本体占用，复核包身份，沿用现有只读遍历（5秒遍历预算、500万条目引擎上限、取消、硬链接去重、跳过符号链接目标／跨设备／私有边界）。统计包含目录分配块，非可回收量；不扫描用户Library关联路径。占用与所选路径／标识匹配才显示。
- 结果支持全部、发现内容、需关注来源；计数基于完整报告，筛选不重新扫描。卸载入口放在所选应用操作区并与只读检查区分，执行确认保持原样。

验证：应用占用身份／路径／链接与硬链接用例；分组／排序／筛选纯函数；两组模拟与新增占用／分组交互；统一检查、打包、完整签名。真实权限矩阵仍待验，不卸载已有软件或修改TCC。

资料：[MangoDisk](https://github.com/pikecode/MangoDisk)、[CleanMyMac应用管理](https://macpaw.com/support/cleanmymac/knowledgebase/uninstaller)、[Space Lens](https://macpaw.com/support/cleanmymac/knowledgebase/space-lens)。
