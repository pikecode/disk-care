# 应用管理键盘焦点往返

目标：补验原生Tab／Enter／Esc，并让详情区可用Esc返回所选列表按钮，便于连续检查应用。

方案一（采用）：详情区Esc仅返回焦点；方案二：Esc清除选择会丢失当前范围，不适合连续操作。本轮保持选中状态，弹窗仍使用自身取消逻辑，作业中不拦截Esc、不隐式扫描。

KISS／DRY：复用列表按钮与现有焦点逻辑；SOLID：焦点导航不改变后端任务状态；YAGNI：不引入快捷键配置或全局键盘管理器。

验证：固定0.9.18原生选择应用只读范围、确认扫描按钮禁用，Tab及Esc焦点；浏览器验证Esc返回及无隐式检查。后端未改，不重跑Rust；打包／签名按产品改动执行，系统权限仍待真实授权用例。
