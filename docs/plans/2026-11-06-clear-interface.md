# 界面信息层级简化

用户反馈：视觉交互不易理解，需简单明了。本轮优先改变操作结构，避免只调整配色。

推荐方案：页面只留一个主要操作，检查范围在点击后以原生dialog确认，结果先给名称／占用／状态，路径及规则按需展开。备选仅缩紧卡片和字号，成本低但不能减少操作理解负担，不采用。沿用现有字体与色彩，不引入新组件库。

范围：统一页面标题说明并去除技术副标题，侧栏弱化重复口号；概览的独立文件夹入口折叠、初始步骤条不展示；开发工具主页面去掉前置表单，点击检查再选工具／项目并明确确认，关闭／Esc不查询。结果的技术依据与覆盖细节按需展开；Homebrew原生命令预览放到高级选项，操作仍显式触发。

保留：检查范围说明、Rust项目绑定、取消／失败／部分统计反馈、无自动分析、无新删除、卸载前独立确认。KISS缩短主要路径，DRY复用原API与样式，SOLID保持显示与执行边界，YAGNI不增加清理功能和新依赖。

验证：主页面首屏主操作可见；确认前零探测；取消／Esc焦点恢复；Rust无目录不可开始、换范围标签；单工具重查、错误／取消、切页、窄窗口。复验独立目录入口与应用卸载模拟；统一检查、打包和完整签名。原生TCC验收不在模拟结果中冒充完成。
