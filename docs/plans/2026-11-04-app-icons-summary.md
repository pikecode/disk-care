# 应用图标、键盘与结果摘要

目标：完善应用管理辨识与检查反馈，保持检查和卸载确认边界。

方案：采用系统 NSWorkspace 图标，前端按可见项请求，失败回退首字；不采用全量图标批量内嵌，避免扩大列表返回体积。PNG 输出限256KiB，向系统请求64点的图像表示，应用身份沿用路径和标识复核；系统图像解码耗时不承诺硬上限。

键盘：列表方向键、Home／End只移动检查按钮焦点，Enter才选择；⌘F在应用管理激活时聚焦搜索。保留原生Tab、对话框Esc和默认取消。

摘要：展示候选条目数（非去重文件数）、检查完整度；逐来源展示已观测分配块占用，不跨来源求和，不称可回收。空来源不能显示检查完整；部分结果保留不完整提示。

文件：后端app_residue.rs／lib.rs及Cargo功能声明；前端AppIcon.tsx／AppResidue.tsx／api.ts／style.css，两组模拟脚本和记录。

KISS：复用原生图标与现有检查组件；DRY：列表和详情共享图标组件；SOLID：图标读取不接触卸载；YAGNI：不新增缓存服务和图标数据库。

验收：身份拒绝与系统图标输出测试、键盘不隐式检查、摘要完整／部分／空来源、回退、窄窗口；统一检查、两组模拟、打包／签名与原生只读窗口。未选择真实软件进行卸载，不操作TCC。
