# 应用管理操作流程简化

目标：让按钮名称与实际操作一致，把高频操作放在所选应用首屏，防止切换目标后误读旧报告。

方案比较：只调整颜色与间距成本低，但无法解决“检查仅选中”“重复确认”“旧报告串目标”；采用复用现有双栏、动作前置与目标绑定。KISS减少常规操作一次重复勾选；DRY复用原检查和卸载接口；SOLID把报告展示匹配留在显示层，不改后端身份／权限保护；YAGNI不加入自动扫描或新删除能力。

1. `AppResidue.tsx`应用行“检查”改为“查看”，明确只选中详情，不自动检查；显示选中状态并保留方向键／Enter／Esc。详情首屏提供检查关联文件与卸载，应用本体占用放在后面，范围技术细节按需展开。
2. 已从列表选中的合法应用，通过明确点击“检查关联文件”确认页面展示的只读范围，不再重复勾选；手动标识、历史标识与特殊样例路径仍保留范围阅读确认，目标改变重置。卸载独立确认、预览过期与执行保护不变。
3. `appAssociation.ts`增加纯展示匹配：应用报告必须标识＋所选包路径一致；手动标识报告必须无应用路径；特殊样例必须匹配准确样例目标。不同目标报告保留于父状态但不在当前详情展示，明确提示当前无匹配报告；切回原目标可恢复可匹配报告。
4. 前端断言补验不同副本、手动与样例互斥；两组应用模拟更新真实报告字段并验证常规两步、手动仍确认、选中不扫描、切换副本不串结果、切回恢复。统一UI七组、全量检查、最低窗口截图、生产包与完整签名。
5. 完成后本地交付0.9.35、保留0.9.34，按分支规则提交、合入和附注标签；不自动推送或操作运行中的旧实例。新包原生权限与首次用户验收继续待验。

结果：七组模拟、前端目标匹配断言、全量Rust101通过／10忽略、构建及两处完整签名通过；0.9.35两个同标识合成应用原生流程通过，夹具清除。旧卸载夹具时序失败改为就绪握手后复验，不放宽实际保护。本地交付0.9.35保留0.9.34，本轮不自动推送。[本轮记录](../change-log.md#change-20261110-007)。
