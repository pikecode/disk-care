# 集中授权引导实施计划

目标：扩展扫描前引导用户一次授予当前应用完全磁盘访问，减少逐目录授权干扰；常规扫描仍无需广泛授权。

方案一（推荐）：系统设置深链加当前应用定位、明确分步说明；方案二：自动授予或用探测文件推断授权，不支持或不可靠，不采用。

遵循 KISS/YAGNI：不建权限状态机，不新增依赖。DRY：复用设置命令，结果页入口同步改善。职责边界：系统负责授权，应用仅引导，确认不代表系统授权。

1. 在 src-tauri/src/lib.rs 增加固定应用定位命令，仅允许由 current_exe 推导 Contents/MacOS 下的 .app，禁止前端传路径；开发模式清楚报错。
2. 设置入口优先打开完全磁盘访问固定深链，命令失败回退设置主页；跳转成功不等于授权成功。
3. src/ScanAccess.tsx 将授权说明改为三步，可定位当前应用、展示路径，设置/定位失败就地反馈；常规模式不要求授权，项目扫描说明可按需授权。
4. src/api.ts 同步命令，测试 app 路径校验；扩展界面测试覆盖定位成功/失败、路径、无自动扫描、无伪造已授权。
5. 更新 docs 及版本 0.8.2，Rust、TypeScript 和相关界面检查通过后原生交付。不会自动操作系统开关、重启应用或删除用户数据。

限制：深链可能被系统接受但未定位目标页，始终保留手动导航说明；没有稳定签名时更新后仍可能需要重新授权。
