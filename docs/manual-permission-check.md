# macOS 原生权限验收

初始清单对应 0.8.2；当前交付为 0.9.2。自动化测试由开发侧负责，本清单只检查模拟 IPC 无法覆盖的真实系统行为。

请使用 release/留白.app；不需要为了测试重置权限，也不需要清理任何数据。

1. 点击「开始扫描」：确认前不应扫描；点击取消应返回原页面。
2. 选择默认常规扫描并开始：记录是否出现系统权限弹窗，以及弹窗提到的文件夹。常规范围只有三个默认缓存，不要求先开启完全磁盘访问。
3. 若需要检查扩展范围，选择扩展扫描，展开目录说明，再明确确认开始。若系统请求访问，可以选择拒绝；结果不应把无法读取的目录报告成完整统计。
4. 查看「本次统计不完整」：核对是否列出受影响的位置；若没有读取问题或中止，不应无故出现警告。
5. 仅在你愿意授予权限时，点击设置入口并自行调整；返回应用不应自动扫描。若系统要求重启应用，重启后再手动选择扩展扫描。

反馈只需提供：应用版本、扫描模式、弹窗文件夹名称、你选择允许还是拒绝、最终页面是否显示不完整。无需提供私人文件内容。

系统现有授权可能使弹窗不出现，这不算失败；本机单次通过不等于所有系统版本均通过。全过程无需点击「确认清理」。

## 0.8.2 集中授权补充

扩展扫描提供三步指引。点击「打开系统设置」应尝试打开完全磁盘访问页面；若未定位，按界面路径手动导航。点击「在 Finder 中定位当前应用」，确认选中的是正在使用的 release/留白.app，而非历史备份，然后由你自行添加并打开权限开关。

设置跳转、Finder 定位、从设置返回均不应自动开始扫描，也不应显示已验证授权。若系统要求重新打开应用，按要求操作后再手动扫描。开发预览中定位失败属于预期，请用打包应用验证。无需为了验收重置已有权限或执行清理。
