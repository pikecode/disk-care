# AI 数据只读规则与兼容范围

日期：2026-10-21。对应 M2 / A1 源码；2026-10-22 已随 0.9.5 本地交付，真实覆盖仍不完整。规则版本 1，全部 `cleanupEligible=false`。

| --- | --- | --- | --- |
| Codex | 规划轮查询到 0.163.0；未验证该版本数据结构 | 默认建议 `~/.codex`，需用户确认，可改为主目录内自定义路径 | 合成及真实元数据已验；覆盖限制见下文 |
| Claude Code | 未验证安装版本 | 默认建议 `~/.claude`，需用户确认，可改为主目录内自定义路径 | 合成及真实元数据已验；覆盖限制见下文 |

官方资料来源见 [专项设计](plans/2026-10-21-ai-workspace-data-design.md)。本模块只用路径线索，不运行工具命令、读取环境或解析正文；界面始终明确版本未验证、活动状态未知。

| 路径线索（保护优先） | 策略 | 影响 |
| --- | --- | --- |
| 凭据、配置文件、记忆、技能、插件、工作树、快照、计划、数据库及侧文件 | 保护 | 可能影响登录、长期记忆、代码或恢复能力 |
| sessions、archived_sessions、projects、附件／工具输出、history.jsonl | 需审阅记录 | 可能用于继续会话；目录名不证明项目归属 |
| log、logs、debug、cache、caches | 未知／待核实 | 仅有名称线索，未验证重建来源和活动状态 |
| 其他 | 未知／待核实 | 不推断无价值或可删 |

完整识别集合以 `src-tauri/src/ai_data.rs` 的 `classify` 为准；这些规则不是已验证版本的官方存储契约。主目录根文件（如 `~/.claude.json`）、默认根外日志、自定义配置、其他用户和其他卷不自动覆盖。未知数据也没有清理入口。

只计普通文件，根内硬链接去重；不跨根累加。分配块和逻辑大小均不是可回收量，目录自身块未统计，APFS 克隆共享空间不能准确归属。修改时间不是最后使用时间，扫描不是原子快照。

每根最多 30 秒、10 万条目、12 层，总计 60 秒。0.9.4 起目录枚举按剩余总条目预算有界缓存名称，逐条检查取消和超时；超过预算保留已观测文件并标部分，不再因单目录超过 1,024 项丢弃整个目录。模型账本原有目录枚举限额与报错语义不变。

拒绝主目录外路径、重复／重叠根、符号链接和跨卷内容。无权限、消失、超限、取消及根身份改变均明确呈现；无已观测项的部分结果占用为未知，不能显示为零。报告仅保留在当前应用内存，尚无基线增长分析。

方案取舍：本期推荐元数据账本，便于核实占用且不暴露正文；结构化元数据关联能提供更细的会话归属，但依赖版本格式验证，留给 A2。KISS 保持单独只读模块，DRY 复用目录句柄和作业互斥，SOLID 分离删除接口，YAGNI 暂不引入正文评分、自动清理和新依赖。

## 2026-10-22 真实只读补验

经用户确认，使用终端测试进程统计默认两个根的元数据，不读取文件正文。Codex 返回 limited（63 分组、129 问题），Claude 返回 skipped（60 分组、64 问题）；均不能认定完整覆盖。仅验证分析入口、保护断言及部分状态能够返回，不证明版本格式兼容，也不替代打包应用的 TCC（系统隐私权限）验收。占用汇总见 [本轮记录](change-log.md#change-20261022-001)。下一步需解释真实覆盖缺口，再闭合 M2；不静默提高扫描上限。

## 2026-10-22 宽目录修复后的补验

真实元数据测试通过，但不代表所有内容都已统计。Codex 的 128 个问题包含 126 个链接／特殊文件跳过及目录深度超限；Claude 的 64 个问题均是链接／特殊文件跳过；两者均未记录到权限拒绝。去重后的说明能同时展示不同原因。仍保留链接、特殊文件及深度边界，未提高总预算；终端权限不代表应用 TCC 状态。[本轮记录](change-log.md#change-20261022-002)。

## 0.9.5 诊断展示

在 Coverage 中增加可选诊断列表，最多 50 条，包含路径、固定原因代码和原始错误；路径最多 4096 字符、错误最多 1024 字符，可能截短。仅保留在当前报告内存，不输出到本轮真实根汇总或持久化 AI 基线；诊断查看不触发新扫描或清理。旧报告没有该字段时隐藏详情，不改变旧覆盖结论。预算、深度和链接边界未变，不能据此推断系统已授权。
